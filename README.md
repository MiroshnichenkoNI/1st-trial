# DOVER + Qwen

Для каждого видео: техническая и эстетическая оценки DOVER и описание от Qwen3-VL-2B-Instruct.

Установка и обработка проверены на Tesla V100 32 GB 12 ноября 2026 года. Результаты и ограничения качества — в [REPORT.md](REPORT.md).

## Установка

Linux x86_64, Python 3.12, NVIDIA-драйвер; целевая GPU — Tesla V100 32 GB.

Системные пакеты для Ubuntu 24.04:

```bash
sudo apt update
sudo apt install python3.12 python3.12-venv python3.12-dev build-essential
```

На Ubuntu 22.04 Python 3.12 нужно установить отдельно вместе с `venv` и заголовками.

```bash
bash setup.sh
```

Скрипт создаёт одно окружение `.venv`, устанавливает зависимости с PyPI, скачивает код DOVER и веса обеих моделей. Версии сохраняются в `out/installed.txt`.

## Обработка

```bash
./run.sh --input /path/to/videos --output out/run1
```

Выбираются `*.mp4` из входной папки. `--videos 1.mp4 2.mp4` задаёт список и порядок. Выходная папка должна быть новой или пустой.

Один проход прогревает модели, второй записывает результаты:

- `videos.jsonl` — `job_id`, `video_id`, две оценки DOVER, описание, число токенов, причина завершения;
- `warmup.jsonl` — результаты прогрева;
- `run.json` — настройки и время рабочего прохода.

Результаты приходят по готовности; `job_id` задаёт исходный порядок. `finish_reason="length"` означает достижение лимита генерации. Для группового режима добавьте `--mode baseline`.

## Сравнение скорости

```bash
.venv/bin/python -B benchmark.py run --input /path/to/ten-videos --output out/benchmark
```

Ровно два запуска: один baseline и один optimized. В каждом — 10 видео прогрева и 50 рабочих заданий. Сравнивается время между 12-м и 32-м завершениями. Окно должно содержать каждое видео дважды; иначе измерение отклоняется. Результат — `comparison.json` с временами и изменением throughput. Повторяемость ускорения по одной паре не оценивается.

Свежие результаты сохранены в `results/`: десять описаний и оценок, оба benchmark-прогона, сравнение и проверка результатов.

## Файлы

- `run.py` — CLI, прогрев и запись результатов.
- `pipeline.py` — групповой и потоковый режимы, фоновая подготовка.
- `pipeline_cuda.py` — кадры, входы моделей, DOVER.
- `qwen.py` — AsyncLLM и передача подготовленных входов.
- `vllm_extensions.py` — штраф повторов и синхронизация CUDA.
- `benchmark.py` — замеры и сравнение.
- `prepare.py` — скачивание кода и весов.
